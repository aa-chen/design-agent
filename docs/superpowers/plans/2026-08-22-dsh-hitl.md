# DeepSeek Harness HITL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Design Agent 对话在本页完成 DeepSeek Harness 的工具批准与向用户提问，同一轮暂停后再继续出字。

**Architecture:** 把 Mux 帧映射和 `respond` 信封抽成纯函数（可单测）；`stream()` 遇到 HITL 只 yield、不结束；UI 用 `HitlDock` 贴在输入框上方，经 `respondHitl` → `POST /dsh/api/respond`。

**Tech Stack:** React 19, Zustand, Vite 7, Vitest, 现有 `@da/ui` + Tailwind。

**Spec:** `docs/superpowers/specs/2026-08-22-dsh-hitl-design.md`

**Branch:** `feat/dsh-hitl`（不要直接在 main 改）。不要在未要求时 git commit。

```ts
export interface AskUserQuestionOption {
  label: string;
  description?: string;
}

export interface AskUserQuestionItem {
  id: string;
  question: string;
  detail?: string;
  header?: string;
  options?: AskUserQuestionOption[];
  multiSelect?: boolean;
}

export type StreamEvent =
  | { type: 'start'; messageId: string }
  | { type: 'delta'; text: string }
  | { type: 'done' }
  | { type: 'error'; message: string }
  | {
      type: 'approval';
      rpcId: string;
      sessionId: string;
      approvalId: string;
      toolName: string;
      callId?: string;
      reason?: string;
    }
  | { type: 'question'; rpcId: string; sessionId: string; questions: AskUserQuestionItem[] }
  | { type: 'hitl-resolved'; kind: 'approval'; approvalId: string }
  | { type: 'hitl-resolved'; kind: 'question'; rpcId: string };

export type HitlRespondPayload =
  | {
      kind: 'approval';
      rpcId: string;
      sessionId: string;
      approvalId: string;
      outcome: 'allowed-once' | 'rejected';
    }
  | {
      kind: 'question';
      rpcId: string;
      sessionId: string;
      answer: { answers: Array<{ id: string; selected: string[]; custom?: string }> };
    }
  | { kind: 'question-cancel'; rpcId: string };

export interface ChatStreamClient {
  stream(req: ChatRequest, signal: AbortSignal): AsyncGenerator<StreamEvent>;
  respond?(payload: HitlRespondPayload): Promise<{ accepted: boolean; reason?: string }>;
}
```

### Task 6: useChatStream 接线

**Files:**
- Modify: `apps/design-agent/src/chat/useChatStream.ts`

在 `for await` 增加：

```ts
case 'approval':
case 'question':
  useChatStore.getState().setPendingHitl(sessionId, event.type === 'approval'
    ? { kind: 'approval', rpcId: event.rpcId, sessionId: event.sessionId, approvalId: event.approvalId, toolName: event.toolName, callId: event.callId, reason: event.reason }
    : { kind: 'question', rpcId: event.rpcId, sessionId: event.sessionId, questions: event.questions });
  break;
case 'hitl-resolved': {
  const pending = useChatStore.getState().pendingHitlBySession[sessionId];
  const match =
    event.kind === 'approval'
      ? pending?.kind === 'approval' && pending.approvalId === event.approvalId
      : pending?.kind === 'question' && pending.rpcId === event.rpcId;
  if (match) useChatStore.getState().clearPendingHitl(sessionId);
  break;
}
```

`error` / `finally` 的 `finishMessage` 保持；`finishMessage` 已清 pending。

`respondHitl`：

```ts
const respondHitl = async (payload: HitlRespondPayload) => {
  if (!client.respond) {
    const sid = useChatStore.getState().activeSessionId;
    if (sid) useChatStore.getState().setPendingHitlError(sid, '当前客户端不支持人工处理');
    return;
  }
  const result = await client.respond(payload);
  const sid = useChatStore.getState().activeSessionId;
  if (!sid) return;
  if (result.accepted || result.reason === 'not-pending') {
    useChatStore.getState().clearPendingHitl(sid);
    return;
  }
  useChatStore.getState().setPendingHitlError(sid, result.reason ?? '提交失败');
};
```

`stop`：若 pending 为 question，先 `client.respond({ kind: 'question-cancel', rpcId })`（catch 忽略），再 abort。

返回 `{ send, stop, respondHitl }`。

`error` case 仍 `return`（结束循环）；HITL 不 return。

### Task 7: HitlDock + ChatInput

**Files:**
- Create: `apps/design-agent/src/chat/HitlDock.tsx`
- Modify: `ChatInput.tsx`, `MessageItem.tsx`, upload buttons

**HitlDock 视觉：** 与现有白底输入卡同一 `max-w-3xl`。批准卡左边 3px `#d97706` 条；提问卡左边 `#2563eb`。字体沿用现有 `text-sm text-gray-800`，不要新字体。

批准：标题「需要批准」、`toolName`、`reason`；按钮「允许一次」「拒绝」。

提问：每题 header/question/detail；options 为 radio 或 checkbox；可选「其他」文本；「提交」。

本地 `validateQuestionAnswers` 失败时在卡内显示错误，不调用 `respondHitl`。

`ChatInput`：

- `busy = streaming || awaiting-hitl`
- `HitlDock` 放在输入白卡片**上方**（仍在 `blockRef` 内，高度计入占位）
- textarea / 上传 `disabled={busy}`
- `busy` 时圆形按钮改为停止（`aria-label="停止"`），`onClick={stop}`，enabled
- 非 busy 时保持发送，`disabled={!text.trim()}`

`MessageItem`：`streaming && content===''` 时，若该 session `awaiting-hitl` 显示「等待你确认…」，否则「正在思考…」。把 `awaitingHitl: boolean` 从 `MessageList` 传入，或 MessageItem 自己读 store（按 `activeSessionId`）。优先 MessageItem 读 `useChatStore` 的该消息所属 session：需要 sessionId。更简单：MessageItem 读 `activeSessionId` 的 status（列表只渲染当前 session）。

Upload：`disabled?: boolean` 传给 Button，并阻止 click。
